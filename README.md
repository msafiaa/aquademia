# Aquademia

**AI-Powered Adaptive Learning Platform with Gamification**

Aquademia is a web-based educational platform developed to support personalised and interactive learning through artificial intelligence and gamification.

## Key Features
- AI-generated learning materials
- Interactive learning activities
- Personalised feedback based on quiz performance
- Gamification-based learning experience

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL

## Project Background
Developed for Festival Idea Putrajaya 2026.
